# XSPedia Web

Struktur frontend dibuat rapi di dalam `public/`.

```text
xspedia-web/
├── public/
│   ├── index.html
│   ├── login.html
│   ├── register.html
│   ├── forgot-password.html
│   ├── dashboard.html
│   ├── profile.html
│   ├── docs.html
│   ├── admin.html
│   ├── style.css
│   └── script.js
├── api/
├── server.js
├── package.json
├── vercel.json
├── .env
└── README.md
```

Semua file HTML berada di `public/`, jadi root project tidak berantakan.
